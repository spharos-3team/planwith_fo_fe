# Plan&With Frontend

여행 일정을 계획하고 공유하는 MSA 기반 서비스 **Plan&With**의 프론트엔드 프로젝트입니다.

## 개발 목표

일정 페이지 개발에 필요한 공통 프론트엔드 환경을 구축합니다.

## 기술 스택

| 구분 | 기술 |
| --- | --- |
| Framework | Next.js |
| Language | TypeScript |
| UI | React |
| CSS | Tailwind CSS |
| Runtime | Node.js |
| Server State | TanStack Query |
| Form | React Hook Form |
| Validation | Zod |
| HTTP | fetch 또는 Axios |

## 완료 조건

- Next.js와 TypeScript 기반 프로젝트 구성
- Tailwind CSS 공통 스타일 환경 구성
- TanStack Query를 이용한 서버 상태 관리 기반 구성
- React Hook Form과 Zod를 이용한 폼 및 검증 기반 구성
- 일정 페이지 개발을 시작할 수 있는 공통 환경 구축
